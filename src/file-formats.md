# File Formats
The custom file formats used throughout P3. The archives come first, since most of the
others are found inside them, and the map and navigation formats follow.

`p2arch0_eng.cpr` and `p2arch1_eng.cpr` are [CPR](./file-formats/cpr.md) archives holding
the game's scripts, images and tile data; the loose files under `Save/` and `iso/` use the
remaining formats on their own. One format sits outside both: `LastWon.eld`
([.eld](./file-formats/eld.md)) is written straight into the game folder.
