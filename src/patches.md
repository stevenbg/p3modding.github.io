# Patches
Small, self-contained edits to `Patrician3.exe` that change one behaviour each - mostly
lifting hardcoded limits or making the interface show numbers it already has. Each page
states what the patch does, the reasoning behind the bytes, and the bytes themselves.

These are binary patches, distinct from the DLL mods loaded by the
[modloader](./modloader.md), and distinct from the [known bugs](./bugs.md), where the fix
sections describe corrections rather than changes in behaviour.
