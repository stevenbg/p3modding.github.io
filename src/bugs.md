# Known Bugs
Defects in the shipped game, identified by the community. Each page follows the same shape:
a **Summary** of what goes wrong, **Details** tracing it to the code responsible, and a
**Fix** giving the bytes that correct it where one is known.

"Bug" here means the code does not do what it evidently intends - a wrong index, a missing
bound, a lock that does not lock. Behaviour that is merely surprising but deliberate is
documented in the chapter it belongs to instead.
